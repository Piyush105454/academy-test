Grading agent — engineer briefing

Four things to know before you wire it into the portal. 212 tests, all passing. Full detail: Engineer-Guide-Portal-Integration in the wiki.

POINT 1

The model scores. Code decides what reaches a child.

Two layers, deliberately separate.

The referee does not second-guess the model's scores. It makes a fixed set of rules hold no matter what comes back — which is the only way they are guarantees rather than hopes about a prompt.

Rule of thumb: if you're about to add a sentence to the prompt to stop something bad, it probably belongs in the referee. Prompts drift between model versions. The referee doesn't.
POINT 2

You implement four Protocols. Nothing else.

Structural typing — no imports from us, no subclassing.

class PortalSource:                      # no base class
    def pending_submissions(self): ...
    def load_module(self, module_id): ...
ProtocolJob
SubmissionSourcePull submissions and modules from the portal
ResultSinkWrite the grade back to the Student Details row

Delete sample_data/modules/ once the portal is wired. A stale local module that silently shadows the portal is how a class gets graded against last term's word list.

POINT 3

Binding is the one to get right first.

A wrong score is recoverable. A wrong binding is not.

If Vivek's video is graded beside Khusi's note, both get plausible feedback about work they never did, and nothing in the text reveals it. At 35–40 students across 6 periods that's ~240 bindings a day.

submission = bind([
    ArtifactRef(submission_id="s-4821", student_id="STU-118",
                module_id="day12_task2_english", kind="video", path=v),
    ArtifactRef(submission_id="s-4821", student_id="STU-118",
                module_id="day12_task2_english", kind="note",  path=n),
])

Identifiers travel with the file, from the portal row — never from a filename. WhatsApp Video 2026-08-30 at 7.15.37 AM.mp4 carries no student and no module.

Let BindingError raise. Do not catch and continue. A swallowed exception here is the failure nobody ever notices.
POINT 4

Responsible AI is code, not a policy document.

Each rule below has tests. Breaking one fails the suite.

RuleWhat it prevents
Consent before the file opensGrading a child nobody agreed to
Coverage checked before scoringMarks deducted for content we never actually heard
Wrong slot ≠ wrong workTelling a child their correct homework was wrong
Missing ≠ unreadableOur OCR failure becoming the student's 0
Abstentions never zeroed or clamped"Couldn't judge" silently becoming "did badly"
Every score cites evidenceA number nobody can question or appeal
Forbidden-inference scanJudgements about ability, effort, family, caste, religion
Profiles bounded & non-comparativeA permanent file on a child; ranking against classmates
The one that keeps being proved right. The forbidden-inference scanner is crude substring matching. During this week's verification pass, "probably from a home without books" and "seems uninterested" both passed it cleanly — two of the eight banned categories, straight through. Both are now caught. The phrasing that gets through is never the phrasing you thought of, which is the argument for scanning at all rather than trusting the prompt. When you see one slip past, add it.
Before this grades anyone: the thresholds are reasoned, not measured — 0.85 Devanagari similarity, 10%/25%/40-word relevance. A teacher marks 10 real submissions, we compare, we adjust. Until then the guarantees are solid and the numbers are guesses.
