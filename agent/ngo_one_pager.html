How the homework agent marks a student's work

One page, plain words. The agent reads a student's video and handwritten note, compares them to the module the teacher set, and writes feedback in English and Hindi. Everything marked in green is a rule that protects the child.

A rule that protects the student An ordinary step

AWhere the agent protects the student

PERMISSION

No consent, no look

The video file is not opened at all until a permission record exists. There is no way to skip this.

FAIRNESS

Never guesses about the child

The agent may never decide a child is clever, lazy, poor, or from any caste or religion. Words like these are blocked before anything is sent.

HONESTY

"I could not tell" is allowed

If the sound is unclear or the writing is hard to read, the agent says so. It never turns "I could not check" into a low mark.

EXPLAINABLE

Every mark has a reason

A mark with no stated reason is rejected. A student who asks "why did I get a 3?" gets an answer.

PERSONAL

Compared only to themselves

"Better than last time" — never "behind the class". Only the last five pieces of work are looked at, so one bad day is not a label.

THE RIGHT TO BE FORGOTTEN

A student can be erased

When a student leaves, everything held about them can be removed with one instruction.

BWhen can a student get a zero?

Only in one situation, and it can be undone.

What happenedMarkWhy
The student did not upload the note at all0The work was not done. If the note arrives later, the agent marks it again and the 0 is replaced
The photo is blurred or the sound is missingNo markThat is our problem, not theirs. The student is asked to upload it again
The work is for a different modulePausedThe teacher moves it to the right place, then it is marked normally

Three things the agent will never do Tell a child their homework was wrong when it was simply filed in the wrong place · Give a low mark because our software could not read something · Say anything about a child's family, ability, effort, caste or religion.
